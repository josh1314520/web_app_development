# 產品需求文件 (PRD) - 食譜收藏夾

## 1. 專案概述

### 背景與動機
在日常生活中，人們常常在網路上或是書籍中看到想試做的食譜，但這些資訊往往散落在各個平台、截圖、或筆記軟體中，缺乏一個統一且有效率的方式來整理與管理。當需要尋找特定的食譜時，往往要花費許多時間翻找。因此，我們希望打造一個專屬的「食譜收藏夾」，讓使用者能輕鬆地記錄、分類並快速搜尋自己喜歡的食譜。

### 目標用戶
- 喜歡料理、烘焙的家庭主婦／夫或單身族
- 剛接觸烹飪，需要記錄實作筆記的新手
- 想要建立個人專屬食譜庫的料理愛好者

### 核心價值主張
提供一個直覺、簡單的介面，協助使用者集中管理所有食譜，透過完善的分類與搜尋功能，大幅縮短尋找食譜的時間，讓下廚變成一件更輕鬆愉快的事。

## 2. 功能需求

### 主要功能清單
1. **新增食譜**：填寫食譜基本資訊，包含標題、食材清單、步驟說明。
2. **分類管理**：為食譜標記分類或標籤（例如：中式、西式、甜點）。
3. **食譜維護**：修改舊有食譜的內容，或是刪除不再需要的食譜。
4. **列表與搜尋**：顯示所有已收藏的食譜清單，並支援關鍵字搜尋。
5. **檢視食譜明細**：點擊單一食譜後，可查看清晰的食材比例與步驟指示。

### 使用者故事 (User Stories)
- **新增食譜**：作為一名 **料理愛好者**，我希望 **能夠新增包含標題、食材與步驟的食譜**，以便 **我能詳細且完整地記錄我的實作心得與配方**。
- **分類管理**：作為一名 **料理愛好者**，我希望 **能夠為食譜標記料理類別（如：中式、甜點）**，以便 **我能在想做特定種類的菜色時快速找到對應的食譜**。
- **食譜維護**：作為一名 **料理愛好者**，我希望 **能夠修改或刪除現有的食譜**，以便 **我可以修正配方錯誤或移除不再需要的舊食譜**。
- **列表與搜尋**：作為一名 **料理愛好者**，我希望 **能看到所有食譜的清單並提供關鍵字搜尋功能**，以便 **當我只記得某個菜名或想要尋找特定菜色時，可以迅速找出該份食譜**。
- **檢視食譜明細**：作為一名 **料理愛好者**，我希望 **能有一個乾淨、易讀的食譜明細畫面**，以便 **在廚房做菜時可以清楚地一邊看步驟一邊操作**。

## 3. 非功能需求

### 技術限制
- 後端框架：使用 Python Flask
- 前端技術：使用 HTML, CSS 與 Jinja2 模板引擎進行渲染
- 資料庫：使用 SQLite 作為輕量級的關聯式資料庫
- 部署環境：可單機運行，適合本地端開發與測試

### 效能與安全考量
- **效能**：系統操作（如新增、搜尋、載入清單）回應時間應在 1 秒以內，以提供順暢的使用體驗。
- **安全性**：防止基本的 SQL Injection 與 XSS（跨站腳本攻擊），尤其在處理使用者輸入的食譜內容時，需進行適當的跳脫與過濾。

## 4. MVP 範圍 (Minimum Viable Product)

- **Must Have (必須有)**
  - 新增食譜（包含標題、食材清單、步驟說明）
  - 檢視所有食譜清單與單一食譜明細
  - 刪除指定的食譜
  - 支援簡單的關鍵字搜尋（針對標題）
  - 標記並檢視單一分類（如：中式、西式）

- **Should Have (應該有)**
  - 修改/編輯已存在的食譜內容
  - 搜尋功能擴展至「食材」的關鍵字搜尋
  - 進階分類管理（支援自訂分類與多重標籤）

- **Nice to Have (加分項)**
  - 食譜圖片上傳與預覽
  - 會員系統與多帳號支援
  - 食譜分享功能（產生專屬連結分享給朋友）
  - 從常見食譜網站透過網址自動爬取並匯入食譜
